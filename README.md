# MediCare

A robust console-based Java application designed for personal medication management and vital health parameter tracking.

## Overview

MediCare provides a secure and structured environment for users to maintain their prescription schedules, manage daily intake reminders, and log critical health metrics with automated timestamping. Built using Object-Oriented Programming principles in Java.

## Features

* **Secure Authentication:** Dynamic user registration and credential validation per session.
* **Medication Management:** CRUD operations for tracking prescriptions, including custom dosages, frequencies, and treatment durations.
* **Intake Tracking:** Interactive reminder state management to mark doses as *Taken* or *Missed*.
* **Health Metrics Logging:** Systematic storage for physiological readings such as blood pressure, blood sugar, weight, and body temperature.
* **Audit Trail:** Chronological history view of all health records and medication events.

## Technical Architecture

* **Language:** Java
* **Core Concepts:** Object-Oriented Design, Inheritance, Polymorphism, Collections Framework (`ArrayList`), Exception Handling.
* **Libraries:** `java.time` (LocalDate and LocalTime APIs).
